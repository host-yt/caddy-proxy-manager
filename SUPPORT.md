# Support

- **Questions and help:** [Discussions](https://github.com/host-yt/caddy-proxy-manager/discussions).
  Check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) first.
- **Bugs and feature requests:** [open an issue](https://github.com/host-yt/caddy-proxy-manager/issues/new/choose)
  using the forms.
- **Security vulnerabilities:** [private advisory](https://github.com/host-yt/caddy-proxy-manager/security/advisories/new).
  Never in issues, Discussions or PRs. See [SECURITY.md](SECURITY.md).

Pull requests are accepted from collaborators only; see [CONTRIBUTING.md](CONTRIBUTING.md).
